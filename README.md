## ✅ Detailed Project Descriptions:

---

### 📂 **1. Blinkit**

- **Project:** **Blinkit Sales Data Analysis**
- **Description:**  
Analyzed **Blinkit (formerly Grofers)** sales data using **Excel Pivot Tables**.  
Key analysis included:  
✅ Category-wise sales performance  
✅ Monthly trends  
✅ Product line contribution  
✅ Visualized using Excel charts and pivots.

- **Tools Used:** Excel (Pivot Tables, Charts)

---

### 📂 **2. Crypto_Analysis**

- **Projects:**
  - **Dogecoin Analysis**
  - **Solana Analysis**

- **Description:**  
Pre-processed cryptocurrency data for **Dogecoin** and **Solana**. Built **Power BI Dashboards** showing:  
✅ OHLC trends  
✅ Monthly and quarterly price changes  
✅ Volume fluctuations  
✅ Overall performance patterns.

- **Tools Used:** Python (Data Cleaning), Power BI (Visualization)

---

### 📂 **3. Recommendations**

- **Projects:**
  - **Book Recommendation System (Different Genres)**  
    📌 Used content-based and collaborative filtering for recommending books across different genres.

  - **Forecasting Energy Demand**  
    📌 Used machine learning models to forecast energy consumption patterns.

  - **Sustainable Eco-Friendly Product Recommender**  
    📌 Built a recommender system suggesting eco-friendly and sustainable products using user preferences.

  - **B.Tech Books Recommender**  
    📌 Recommended educational books for B.Tech students based on their field and interests.

- **Tools Used:** Python (Scikit-learn, Surprise, Pandas, NLP), Power BI (for visualization)

---

### 📂 **4. Sales**

- **Projects:**
  - **Automobile Sales Analysis**  
    📌 Analyzed sales data of the automobile sector focusing on trends, regional performance, and forecasting.

  - **Walmart Sales Analysis**  
    📌 Performed retail sales analysis for Walmart stores, identifying monthly growth, top-performing categories, and revenue drivers.

- **Tools Used:** Python (Pandas, Matplotlib), Power BI

---

### 📂 **5. Weather_Forecasting**

- **Projects:**
  - **Weather Analysis & Forecasting for 9 Indian States**  
    📌 Used time series forecasting techniques to predict weather parameters (Temperature, Rainfall, Wind Speed, Pressure) for 9 Indian states.

  - **Karnataka Weather Forecasting (Weather-TS Project)**  
    📌 Focused forecasting on Karnataka state using **ARIMA**, **SARIMA**, and **LSTM models**. Built a **Power BI dashboard** to visualize the forecast.

- **Tools Used:** Python (Statsmodels, Keras), Power BI
